# Симулятор Равшана — браузерная версия

Браузерный порт оригинальной WPF-игры.

## Файлы

- `index.html` — интерфейс
- `style.css` — оформление
- `game.js` — игровая логика

## Запуск

Открой `index.html` в браузере.

## GitHub Pages

В репозитории GitHub открой:

**Settings → Pages → Deploy from a branch → main → / (root)**

После публикации адрес будет примерно таким:

`https://pelmeni1floppa.github.io/Ravshan_game_web/`
